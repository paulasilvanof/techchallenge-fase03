Este repositório contém os entregáveis desenvolvidos para o **Tech Challenge – Fase 3**, com foco na **construção de uma arquitetura de dados baseada em conceitos de Big Data, Data Lake, processamento distribuído e computação em nuvem.**

O projeto utiliza dados relacionados ao mercado brasileiro de Dados, Tecnologia e Inteligência Artificial, com o objetivo de realizar o processamento, tratamento, organização e análise dessas informações, permitindo identificar padrões relacionados ao perfil dos profissionais, tecnologias mais utilizadas, senioridade, localização, modelo de trabalho e adoção de Inteligência Artificial.

A solução foi desenvolvida utilizando serviços da **Amazon Web Services (AWS)**, principalmente **Amazon S3, AWS Glue, Glue Data Catalog, Apache Spark/PySpark e ferramentas de consulta analítica.**

Este repositório foi estruturado de forma a representar, de maneira simplificada, a arquitetura implementada na AWS. Dessa forma, as pastas e arquivos aqui disponibilizados reproduzem o fluxo de processamento dos dados, desde a ingestão dos arquivos brutos até a disponibilização das tabelas analíticas utilizadas nas análises finais.
