A camada **Bronze** contém os dados em seu formato original, preservando as informações provenientes da fonte sem alterações significativas. Também adicionamos a catalogação dos dados brutos.

Essa camada funciona como o **ponto inicial do Data Lake** e permite manter uma cópia dos dados brutos para rastreabilidade e eventuais reprocessamentos.

* Dados: Dados brutos disponibilizados na plataforma Kaggle.
* Catalogação: Dados brutos catalogados.
