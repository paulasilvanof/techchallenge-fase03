A camada **Silver** contém os dados após os processos de limpeza, transformação e padronização.

Entre os tratamentos realizados estão:

* tratamento de valores ausentes;
* correção e padronização de tipos de dados;
* tratamento de valores inválidos;
* padronização de categorias;
* organização das variáveis;
* criação de colunas auxiliares;
* preparação dos dados para análise.

Os processos de transformação foram desenvolvidos utilizando **Apache Spark/PySpark, no AWS Glue.** 

* ETL: Código utilizado no AWS Glue para a etapa de ETL dos dados.
* Dados: Tabelas disponibilizadas em formato .csv e .parquet.
* Catalogação: Dados catalogados após os processos de limpeza, transformação e padronização.
